1. 歧义默认值：以下词在中文有多义，**一律按游戏/开发含义翻译**：
   - Engine = 游戏引擎（不译“发动机”，除非明确是汽车/机械语境）
   - Patch = 补丁 / 版本更新（不译“布片”）
   - Season = 赛季（LiveOps / 战斗通行证语境）
   - Build = 构建版本 / 开发构建（不译“身材”）
   - Drop = 掉落 / 发售投放（视上下文；音乐发行语境可保留 drop）
   - Agent = 智能体 / AI 角色（游戏 AI 语境；不译“代理人”，除非商务代理）
   - Shader = 着色器（保留或译“着色器”）
   - Pipeline = 管线（美术/构建管线）
   - LiveOps / Live Ops = 线上运营 / LiveOps（可保留英文）
   - Early Access = 抢先体验
   - Soft launch = 软启动 / 小范围上线
   - Day-one / Day 1 patch = 首日补丁
